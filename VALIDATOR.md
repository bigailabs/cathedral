# Cathedral Validator moved

[`cathedralai/cathedral-validator`](https://github.com/cathedralai/cathedral-validator)
is the sole Cathedral validator operator repository.

Use its:

- [operator README](https://github.com/cathedralai/cathedral-validator#readme);
- [validator runbook](https://github.com/cathedralai/cathedral-validator/blob/main/VALIDATOR.md);
- [release page](https://github.com/cathedralai/cathedral-validator/releases);
- [issues](https://github.com/cathedralai/cathedral-validator/issues).

Do not install, configure, release, or broadcast a validator from this
repository. Validator code and deployment fixtures still present here are
legacy mechanism and migration references, not a supported operator path.
