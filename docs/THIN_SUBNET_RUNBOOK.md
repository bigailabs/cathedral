# Thin subnet notes moved

The supported validator runbook lives in
[`cathedralai/cathedral-validator`](https://github.com/cathedralai/cathedral-validator/blob/main/docs/THIN_SUBNET_RUNBOOK.md).

This repository retains thin-subnet mechanism and miner modules for research,
contract tests, and migration review. It does not publish a supported thin or
SN39 validator command. Do not install a validator unit or broadcast weights
from this repository.

For current miner roles, use:

- [`cathedral-compute`](https://github.com/cathedralai/cathedral-compute) for
  Intel TDX CPU compute
- [`cathedral-distill`](https://github.com/cathedralai/cathedral-distill) for
  Distill work
- [`cathedral-cli`](https://github.com/cathedralai/cathedral-cli) for early-beta
  workflow testing
