# Validator provenance documentation moved

The current provenance contract and operator procedure live in
[`cathedralai/cathedral-validator`](https://github.com/cathedralai/cathedral-validator/blob/main/docs/PROVENANCE.md).

This repository keeps publisher and mechanism-side provenance code for tests
and migration review. It does not publish a supported validator command,
configuration, release, or deployment path.

Do not use historical instructions from this repository to install or run a
validator.
